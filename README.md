# Product Review Tracker

Portfolio project for aspiring **DevOps / SRE** engineers: build a full-stack CRUD app **yourself** using step-by-step lab manuals, then deploy with Docker, AWS, Terraform, Ansible, and GitHub Actions.

## How This Repo Works (Important)

This is **not** a “clone and run” template.

| Folder | Purpose |
|--------|---------|
| **[docs/labs/](docs/labs/)** | **Lab manuals** — full file paths, complete code, test steps (start here) |
| **[docs/](docs/)** | Concept guides, roadmap, troubleshooting, interview prep |
| **`backend/`, `frontend/`, …** | **You create these** by following the labs |
| **[reference/](reference/)** | Answer key only — use after you try, or to diff one file |

Read: **[docs/16-HANDS-ON-LEARNING-GUIDE.md](docs/16-HANDS-ON-LEARNING-GUIDE.md)**

## What You Will Build

Track products from brands (keyboards, mice, beauty, tech, etc.):

- Received / reviewed / posted (Instagram, TikTok, YouTube)
- Ratings, notes, deadlines, sponsorship status

**Stack:** FastAPI · React · Vite · Tailwind · PostgreSQL · Docker · AWS EC2 · Terraform · Ansible · GitHub Actions · Prometheus · Grafana
