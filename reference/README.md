# Reference Solution (Answer Key)

This folder contains a **complete working implementation** of Product Review Tracker.

## Important — Read This First

Per the [Hands-On Learning Guide](../docs/16-HANDS-ON-LEARNING-GUIDE.md), you should **build the project yourself** by following the lab manuals in `docs/labs/`. Do not copy this folder into your working tree until you have tried building on your own.

## When to Use This Folder

| Situation | What to do |
|-----------|------------|
| You are learning (Week 1–6) | Follow `docs/labs/` — create files manually |
| You are stuck after debugging | Compare **one file at a time** with `reference/` |
| You finished a lab | Diff your file vs reference to catch typos |
| You want to run a demo quickly | Copy specific files only after completing that lab |

## Contents

| Path | What it is |
|------|------------|
| `backend/` | FastAPI + SQLAlchemy API |
| `frontend/` | React + Vite + Tailwind UI |
| `docker-compose.yml` | Local full stack |
| `terraform/` | AWS EC2 IaC |
| `ansible/` | Server provisioning |
| `.github/workflows/` | CI/CD pipeline |
| `monitoring/` | Prometheus + Grafana |

**Do not treat this as the primary learning path.** Muscle memory comes from typing and pasting from the lab manuals, not from cloning a finished repo.
